# PoMoDoRo Presentation Video

This repository hosts the official presentation video and cover image for the PoMoDoRo Chrome extension.

## About PoMoDoRo
PoMoDoRo is a productivity Chrome extension designed to help users manage their time efficiently using the Pomodoro technique. It offers a simple, intuitive interface, customizable timers, and helpful notifications to maximize focus and productivity.

## Files
- **PoMoDoRo.mp4**: Official presentation video
- **PoMoDoRo-Couverture.jpg**: Cover image for the extension

## How to Access
You can view or download the presentation video and cover image directly from this repository. To watch the video online, GitHub may not support direct playback for large files, but you can download and play it locally.
